# power-bisect

Прошивки під один конкретний замір: **куди тече 0,94 мА в deep sleep**.
Питання, підозрювані й арифметика — `docs/струм-сну.md`. Тут — як прогнати.

Не бойове й не стендове. Кожне середовище відрізняється від попереднього рівно
одним доданим блоком ініціалізації, більше в них нема нічого.

| середовище | що робить | що показує |
|---|---|---|
| `idle_awake` | не спить, порожній `loop()` | скільки їсть плата в неспанні без нічого |
| `idle_awake_80` | те саме на 80 МГц | ціна частоти |
| `step_a_sleep` | тільки `esp_deep_sleep_start()` | підлога плати: LED, CP2102, LDO, charger |
| `step_b_radio` | A + SPI + `radio.begin()` + `radio.sleep()` | ціна SX1262 |
| `step_c_periph` | B + Vext + два I2C + дисплей | ціна периферії й підтяжок |

Контроль (крок D) — бойова `greenhouse-node-lowpower`, вона вже дала 0,94 мА.

## Як залити

```
make deploy PROJECT=power-bisect PIO_ENV=step_a_sleep
```

Кроки A/B/C прокидаються раз на 10 хвилин, нічого не роблять і лягають назад:
щоб плата не виглядала мертвою. На показ приладу це не впливає — пробудження
триває частки секунди.

Serial у всіх середовищах мовчить: замір іде на батареї з від'єднаним USB,
друкувати нема кому. Разовий діагностичний прогін по USB, щоб побачити коди
повернення радіо:

```
PLATFORMIO_BUILD_FLAGS=-DAGRO_DEBUG_SERIAL \
  make deploy PROJECT=power-bisect PIO_ENV=step_b_radio
make monitor PROJECT=power-bisect
```

`radio.sleep -> 0` означає, що чип таки заснув. Ненульовий код — знайшли
винного, дивитись `docs/струм-сну.md`, кандидат 3.

## Порядок заміру

Прилад лишається в розриві «мінуса» банки на весь прогін. Між кроками
міняється **тільки прошивка**: та сама банка, той самий діапазон, ті самі
дроти. Інакше різницю між кроками не можна буде приписати прошивці.

1. Сенсори від'єднати всі. Щуп уже виключений заміром (`струм-сну.md`), але
   тут перевіряється підлога, і зайвий споживач її зіпсує.
2. Залити крок, **від'єднати USB**. З USB замір не має сенсу: живлення йде не
   з банки, а CP2102 і контролер заряду при цьому активні.
3. Дочекатись, поки число вгамується (кроки A-C: секунди), записати.
4. Наступний крок.

## Куди дивитись за результатом

- **A вже дає 0,94** — це залізо. Прошивка безсила.
- **стрибок на B** — радіо: `radio.sleep()`, стан `NSS`/`RST` у сні, TCXO
  через DIO3.
- **стрибок на C** — периферія або підтяжки I2C: стан GPIO41/42 у сні.
- **стрибок аж на D** — щось у бойовій логіці, чого нема в A-C.

Перед усім цим є перевірка на п'ять секунд, яка не потребує ні заливки, ні
приладу: **подивитись на плату в темряві, поки вона спить**. Світлодіод
живлення/заряду — кандидат 1, і ~1 мА підозріло добре лягає на заміряні 0,94.
