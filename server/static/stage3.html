Етап 3 · опорний проти сну

—

Два вузли міряють той самий ґрунт. Опорний шле безперервно; той, що зі сном, прокидається раз на кілька хвилин, віддає пачку замірів і засинає. Питання етапу — чи однаково вони міряють. Для кожного беремо ґрунт за вікно й зводимо в середнє / мін / макс; у сплячого це природно виходить усередненням по його останній передачі, бо решту часу даних просто нема.
