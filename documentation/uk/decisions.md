## Що ще не вирішено

- Параметри LoRa (SF/BW/потужність) — дефолти RadioLib, не обирались свідомо.
- Чим замінити `map()` для ґрунту: формула чи таблиця.
- Бінарний пакет замість JSON — коли і чи треба.
- Hub-модель з одним ботом на багато господарств — чи буде взагалі.
