# Хмарна телеметрія калібрування

`cloud/soil-telemetry/` — приймач пачок зі стендової плати і сторінка для
телефона. **Не бойовий сервер**: бойові дані ніколи не виходять за межі Pi.
Ця гілка існує для одного: знімати калібрування в теплиці без ноутбука.

## Навіщо і як

```
 Heltec V3 (soil-calibration, env wifi_field)
   │  буфер 30 замірів → раз на 30 с POST /api/ingest (радіо вмикається лише на відправку)
   ▼
 хотспот телефона ──LTE──► Vercel: FastAPI  ◄──► Neon: Postgres
                               │
                               └─► сторінка: живі значення, σ за хвилину, графік, кнопка «влив N мл», CSV
```

USB-CSV на платі **не вимикається ніколи** — це опорний тракт, по якому хмара
звіряється (фаза 4).

## Стек

FastAPI на Vercel (serverless), Postgres у Neon через pooled connection.
Файли: `main.py` (усі маршрути), `public/index.html` (сторінка), `schema.sql`
(виконати раз руками), `requirements.txt` (fastapi, psycopg), `vercel.json`.

## API

| Метод | Шлях | Токен | Що |
|---|---|---|---|
| POST | `/api/ingest` | так | пачка з плати; дубль `(device, seq)` → 200 без запису; у відповіді може бути `pour_ml` |
| POST | `/api/pour` | так | `{device, ml}` — кнопка «влив»; плата отримає при наступному POST |
| GET | `/api/devices` | — | плати, `last_seen`, `stale` |
| GET | `/api/live?device=` | — | останні 240 замірів, `sigma_mv` за 60 с по каналах, недоставлені доливи |
| GET | `/api/export.csv?device=&since=&until=` | — | CSV з колонками USB-логу + `received_at` |
| GET | `/api/health` | — | БД відповідає? токен увімкнений? |

Токен — `Authorization: Bearer <INGEST_TOKEN>`: на запис обов'язковий, читання
відкрите (це калібрувальна телеметрія, не секрети).

**Контракт пачки** (`docs/INGEST-CONTRACT.md`): `device`, `seq`, `labels`,
`samples[]` по 30; `t` — секунди від старту прогону; відсутнє поле ≠ нуль;
дедуплікація за `(device, seq)`; на платі черга на 4 пачки в RAM, щоб пережити
короткий обрив.

**Долив через хмару** — кнопка не пише воду в базу напряму: кладе запис у
`pours`, плата забирає його в полі `pour_ml` відповіді на свій наступний
`/api/ingest`, застосовує (`water_ml += ml`, подія `water+N`), і коли ця подія
приїжджає в пачці — долив позначається доставленим. Так USB-CSV і хмара
показують **однакову** воду, і їх можна порівняти `diff`-ом.

## Розгортання (раз, ~10 хв)

1. Neon → новий проєкт → SQL Editor → виконати `schema.sql`. Connection string
   брати **pooled** (адреса з `-pooler`).
2. Vercel → Add New Project → цей репозиторій → **Root Directory:
   `cloud/soil-telemetry`** (монорепо; інакше Vercel не знайде `main.py`).
3. Env: `DATABASE_URL` (pooled), `INGEST_TOKEN` (`openssl rand -hex 24`).
4. Deploy → `/api/health` має відповісти `{"ok":true,…}`.
5. Той самий URL і токен — у `firmware/.env` (`INGEST_URL`, `INGEST_TOKEN`) →
   `make deploy-soil-cal PIO_ENV=wifi_field`.

Локально замість хмари: `tools/ingest_sink.py --port 8010 --token …` або
`uvicorn main:app --port 8010` з локальним Postgres.

## Телефон як хотспот (iPhone)

Три налаштування, без яких «не працює» виглядає як неправильний пароль:
**«Максимальна сумісність»** увімкнути (інакше 5 ГГц, ESP32 бачить лише 2,4);
перейменувати телефон **без апострофа й пробілу**; тримати екран режиму модема
відкритим при першому підключенні.
